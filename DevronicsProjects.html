Step-by-step guide: adding a project

1

Open the form

Press ＋ Add Project at the top of the page. The upload form opens in a glass panel.

2

Name & categorize

Give the project a clear title and pick a category such as Robotic Arm, Line Follower or Drone. Add comma-separated tags (ESP32, PID, servo…).

3

Describe the build

Write what it does, the parts you used and what you learned. Then add a project picture (optional) — it becomes the card cover.

4

Add your code

Paste the code, or press Upload code file to load a .ino, .py, .cpp or .txt file straight into the editor.

5

Link the video

Paste your YouTube link (watch, youtu.be or Shorts all work). Add a GitHub link too if you have one.

6

Save & share

Press Save project. It appears in the grid instantly. Use Claude’s Share menu to send this page’s link to anyone.

Adding more later: repeat steps 1–6 for every new project. Open any card to view its code, copy it, watch the video, edit it or delete it. Everything you publish is visible to anyone who opens this page; only you (and invited editors) can add or change projects.
